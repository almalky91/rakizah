# AI Chatbot Integration - SkillChatbotDialog

## Overview

The `SkillChatbotDialog` component has been **completely refactored** to integrate with the real AI chatbot API endpoint (`/api/chatbot`) powered by DeepSeek. This replaces the previous dummy data system with intelligent, context-aware responses.

## Changes Made

### 1. **Removed Dummy Data System**

**Before:**
- Used static conversation trees from `@/lib/dummyData`
- Pre-defined conversation nodes with fixed paths
- Limited to scripted responses

**After:**
- Dynamic AI-generated responses via `chatbotApi.sendMessage()`
- Context-aware conversations that adapt to student questions
- Intelligent follow-up questions generated by AI

### 2. **State Management Updates**

**Removed States:**
- `conversation: SkillConversation` - No longer needed (no tree structure)
- `currentNodeId: string` - No nodes to track
- `conversationEnded: boolean` - Conversations flow naturally

**New States:**
- `conversationHistory: Array<{role, content}>` - Maintains context for AI
- `error: string | null` - Handles API errors gracefully
- `currentOptions: ResponseOption[]` - Dynamically updated follow-up questions

### 3. **Core Functions Refactored**

#### `loadInitialResponse()` - NEW
Replaces the initial dummy data loading:
```typescript
const loadInitialResponse = async () => {
  setIsLoading(true);
  
  // Request initial skill explanation from AI
  const response = await chatbotApi.sendMessage({
    message: 'اشرح لي هذه المهارة',
    skillId,
    conversationHistory: [],
  });
  
  // Display AI response with follow-up options
  addMessage({ role: 'ai', content: response.response, ... });
  setCurrentOptions(convertToResponseOptions(response.options));
  
  setIsLoading(false);
  setIsTyping(true);
};
```

#### `handleResponseSelect()` - REFACTORED
Now calls the AI API instead of navigating conversation tree:
```typescript
const handleResponseSelect = async (option: ResponseOption) => {
  // Add student message
  addMessage({ role: 'student', content: option.text, ... });
  
  // Update conversation history for context
  const updatedHistory = [...conversationHistory, { role: 'user', content: option.text }];
  
  // Get AI response with full context
  const response = await chatbotApi.sendMessage({
    message: option.text,
    skillId,
    conversationHistory: updatedHistory,
  });
  
  // Display AI response with new follow-up options
  addMessage({ role: 'ai', content: response.response, ... });
  setCurrentOptions(convertToResponseOptions(response.options));
};
```

### 4. **Helper Functions Added**

#### `convertToResponseOptions()`
Converts AI-generated strings to `ResponseOption` format:
```typescript
const convertToResponseOptions = (options: string[]): ResponseOption[] => {
  return options.map((text, index) => ({
    id: `opt_${Date.now()}_${index}`,
    text,
    nextNodeId: null, // Not used with AI (no tree structure)
  }));
};
```

#### `generateMessageId()`
Generates unique IDs for messages (moved from dummyData):
```typescript
const generateMessageId = (): string => {
  return `msg_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
};
```

### 5. **Error Handling**

Added comprehensive error handling for API failures:

```typescript
// Error state
const [error, setError] = useState<string | null>(null);

// Error display in UI
{error && (
  <div className="bg-destructive/10 border border-destructive/20 rounded-lg p-4">
    {error}
  </div>
)}

// Error handling in API calls
try {
  const response = await fetchAIResponse(userMessage);
  // ... handle response
} catch (error) {
  setError('عذراً، حدث خطأ في الحصول على الرد. يرجى المحاولة مرة أخرى.');
  setIsLoading(false);
}
```

### 6. **Conversation Context**

The component now maintains full conversation history for context-aware responses:

```typescript
const [conversationHistory, setConversationHistory] = useState<Array<{
  role: 'user' | 'assistant';
  content: string;
}>>([]);

// Updated after each exchange
setConversationHistory([
  ...conversationHistory,
  { role: 'user', content: studentMessage },
  { role: 'assistant', content: aiResponse },
]);
```

This allows the AI to:
- Remember previous questions and answers
- Provide coherent follow-up explanations
- Adapt responses based on conversation flow

## API Integration Details

### Endpoint Used
`POST /api/chatbot`

### Request Format
```typescript
{
  message: string;           // Student's question
  skillId: string;          // UUID of the skill
  conversationHistory?: {   // Previous conversation for context
    role: 'user' | 'assistant';
    content: string;
  }[];
}
```

### Response Format
```typescript
{
  data: {
    response: string;       // AI's explanation (in Arabic)
    options: string[];      // Follow-up questions (2-4 suggestions)
  }
}
```

### Security Features
The API endpoint includes:
- Input sanitization (prompt injection prevention)
- Content filtering
- AI instructions to stay on-topic
- Rate limiting (backend)

## User Experience Flow

### 1. **Dialog Opens**
- Student clicks on skill card
- `loadInitialResponse()` is called
- Loading state displays with animation
- AI generates initial explanation of the skill

### 2. **Initial Response**
- AI response displays with typewriter effect
- Conversation history updated
- 2-4 follow-up question buttons appear
- Student can select a question or close dialog

### 3. **Follow-up Questions**
- Student clicks a follow-up question
- Question added to chat as student message
- Loading state displays
- AI generates contextual response
- New follow-up questions appear
- Cycle continues as long as student engages

### 4. **Dialog Close**
- Student can close dialog anytime
- All state is cleared (conversation history, messages, etc.)
- Next time dialog opens, conversation starts fresh

## Migration Guide

### From Dummy Data to AI (for other components)

If you have other components using the old dummy data system:

1. **Remove imports:**
```typescript
// Remove:
import { getConversation, getNode, dummyData } from '@/lib/dummyData';
import type { SkillConversation, ConversationNode } from '@/types/chatbot';

// Add:
import { chatbotApi } from '@/lib/api-client';
```

2. **Replace state:**
```typescript
// Remove:
const [conversation, setConversation] = useState<SkillConversation | null>(null);
const [currentNodeId, setCurrentNodeId] = useState<string | null>(null);

// Add:
const [conversationHistory, setConversationHistory] = useState<Array<{
  role: 'user' | 'assistant';
  content: string;
}>>([]);
const [currentOptions, setCurrentOptions] = useState<ResponseOption[]>([]);
```

3. **Replace API calls:**
```typescript
// Remove:
const conversation = getConversation(skillId);
const node = getNode(conversation, nodeId);

// Add:
const response = await chatbotApi.sendMessage({
  message: userMessage,
  skillId,
  conversationHistory,
});
```
